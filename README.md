# Rummy Club

[English](README_EN.md) | [Русский](README.md)

Небольшая многопользовательская веб-игра для перерыва с коллегами. Создайте комнату, пригласите 2–4 игроков, при необходимости добавьте ботов и общайтесь во встроенном чате.

## Возможности

- приватные комнаты и необязательный публичный список открытых лобби;
- вход по нику без регистрации;
- приглашение в комнату по ссылке;
- 2–4 участника, боты и автоматическая замена вышедших игроков;
- три режима раздачи: классический, сбалансированный и лёгкий;
- таймер хода: без ограничения, 30 секунд, 1, 2, 3 или 5 минут;
- защита от неактивности: при таймере игрок исключается после 3 пропущенных по времени ходов, без таймера — после 30 минут без завершения хода;
- чат комнаты с последними 80 сообщениями;
- локальный черновик хода, который хранится только в браузере;
- автоматическое закрытие комнат и физическое удаление старых данных;
- политика конфиденциальности по адресу `/privacy` и условия использования по адресу `/terms`.

## Стек

- TypeScript
- React
- Vinext / Vite
- SQLite со схемой и миграциями на базе Drizzle
- Docker
- Nginx и Certbot для HTTPS в production

## Требования

- Node.js `>=22.13.0`
- npm
- Docker и Docker Compose для production-развёртывания

## Локальная разработка

Установите зависимости и запустите сервер разработки:

```bash
make install
make dev
```

Полезные команды:

```bash
make help
make build
make start
make lint
```

Локальная SQLite-база создаётся в `data/rummy-club.db`, если не задана переменная `RUMMY_DB_PATH`.

## Развёртывание в Docker

Создайте `.env` на основе примера:

```bash
cp .env.example .env
```

Укажите `DOMAIN` и `CERTBOT_EMAIL`, затем запустите стек:

```bash
make up
```

После обновления исходников пересоберите и перезапустите контейнеры:

```bash
make rebuild
```

Полезные команды для production:

```bash
make status
make logs
make logs-app
make logs-nginx
make logs-certbot
make shell
```

Остановить сервисы без удаления постоянных томов:

```bash
make down
```

Не выполняйте `docker compose down -v`, если не хотите удалить SQLite-базу и сертификаты, хранящиеся в Docker volumes.

Подробности о Docker-развёртывании — в [`README-DOCKER.md`](README-DOCKER.md).

## Переменные окружения

- `DOMAIN` — публичный домен приложения, используемый Nginx и Certbot;
- `CERTBOT_EMAIL` — email для Certbot;
- `RUMMY_DB_PATH` — путь к SQLite-базе. По умолчанию `/app/data/rummy-club.db`.

Используйте `.env.example` как шаблон. Настоящие `.env` и локальные файлы базы игнорируются Git.

## Хранение данных

Состояние комнаты, включая ники игроков и чат, хранится в SQLite, пока комната активна. Закрытые и завершённые комнаты физически удаляются после срока хранения; неактивные лобби удаляются после более длительного срока истечения.

Для игры не нужны аккаунты или email. Браузер использует техническую cookie, чтобы сохранять связь игрока с его местом в комнате.

## Структура проекта

- `app/` — страницы, страницы политики/условий и API-маршруты;
- `components/` — переиспользуемые UI-компоненты;
- `lib/` — правила игры, боты, чат, комнаты, проверки и утилиты;
- `db/`, `drizzle/` — адаптер базы, схема и миграции;
- `docker/`, `nginx/`, `Dockerfile`, `docker-compose.yml` — production-развёртывание;
- `scripts/` — служебные скрипты миграции базы;
- `Makefile` — основные команды разработки и Docker.
